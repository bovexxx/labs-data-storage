# Хранилища данных — ЛР1. Вариант 9

**Тема:** система, описывающая работу одного из участков автосалона — **отдел продаж автомобилей**.

Отдел ведёт склад автомобилей (марка → модель → комплектация, цвет, VIN, статус),
работает с клиентами (данные и документы), проводит тест-драйвы, заключает договоры
купли-продажи с дополнительным оборудованием, принимает платежи и автомобили в trade-in.

| Папка | Файл | Что это |

## Модель в 3НФ — таблицы

| Группа | Таблицы |
|---|---|
| Автомобили | `marka`, `tip_kuzova`, `model`, `komplektatsiya`, `tsvet`, `status_avtomobilya`, `avtomobil`, `dop_oborudovanie` |
| Клиенты | `klient`, `dokument` |
| Персонал | `dolzhnost`, `sotrudnik`, `uchet_zapis` |
| Продажа | `test_drayv`, `status_dogovora`, `dogovor_prodazhi`, `pozitsiya_dop`, `trade_in`, `sposob_oplaty`, `platezh` |

Основные связи:
- марка 1 : N модель; тип кузова 1 : N модель; модель 1 : N комплектация;
- комплектация / цвет / статус 1 : N автомобиль (конкретная машина с уникальным VIN);
- клиент 1 : N документ; должность 1 : N сотрудник; сотрудник 1 : 1 учётная запись;
- тест-драйв связывает автомобиль, клиента и менеджера;
- договор продажи: клиент + менеджер + автомобиль (1 : 1, машину можно продать один раз) + статус;
- договор M : N доп. оборудование через `pozitsiya_dop` (с фиксацией цены на момент продажи);
- договор 1 : N платёж, договор 1 : 0..1 trade-in.

## Модель Data Vault

- **Хабы** (бизнес-ключи): марка, тип кузова, модель, комплектация, цвет, статус, автомобиль (VIN),
  доп. оборудование, клиент (телефон), должность, сотрудник (телефон), договор (номер).
- **Линки**: модель–марка–кузов, комплектация–модель, автомобиль–комплектация–цвет–статус,
  клиент–документ, сотрудник–должность, сотрудник–учётная запись, тест-драйв, договор,
  договор–доп. оборудование, платёж, trade-in.
- **Сателлиты** хранят описательные атрибуты с историей (`load_date`, `load_end_date`, `hash_diff`).
- Во всех таблицах есть `load_date` и `record_source`; ключи — MD5-хэши (`CHAR(32)`).

## Как открыть в MySQL Workbench

1. `File → Import → Reverse Engineer MySQL Create Script…` → выбрать `.sql` → отметить «Place imported objects on a diagram».
2. `File → Save Model As…` → получится файл `.mwb`.
3. Либо выполнить скрипт на сервере (`File → Open SQL Script` → ⚡) и затем `Database → Reverse Engineer`.
